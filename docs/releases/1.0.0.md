The first numbered release. Installs and updates now follow releases.

- **Updates are safe to run.** The installer backs up the database before an update, and puts the previous version back by itself if the new one does not start.
- **Rollback.** `curl -fsSL https://raw.githubusercontent.com/pulicafranaru/vibestream/main/install.sh | sudo bash -s -- rollback` returns to the version before the last update.
- **Choose a version.** `VIBESTREAM_VERSION` picks a release to stay on, or `edge` for untested builds of the main branch.
- **Update notice.** The dashboard says when a newer release is out (Sources, Privacy, Look for updates).
- **TorBox.** Addon releases can be fetched through TorBox with an API key.
- **qBittorrent 5.1 and earlier** sign in again.
